# AVL Tree Interactive CLI

This project implements a self-balancing Binary Search Tree known as an **AVL Tree** in Python. It includes support for insertion, deletion, balancing via rotations, and a simple command-line interface to interact with the tree.

## Features

- **AVL Tree Implementation**: Automatically balances the tree after insertions and deletions.
- **Rotations**: Handles left and right rotations to maintain balance.
- **Height Tracking**: Each node stores its height for balance factor calculation.
- **Interactive CLI**: Insert or delete integers interactively via the terminal.
- **Tree Visualization**: ASCII-style display shows the structure of the tree after each operation.

## Usage

Run the script using any Python 3 interpreter:

```bash
python avl_tree.py
